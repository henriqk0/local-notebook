# pynotebook

A minimal terminal-based NotebookLM-style app built with Textual.

## Setup

- Set `OPENROUTER_API_KEY` environment variable (or configure via in-app setup)
- Install ranger for file picker: `ranger` (optional - fallback path input exists)

## Usage

Run: `uv run pynotebook`

## Keybindings

See in-app help (`?`) for full keybindings.

## Limitations

As per project scope - minimal feature set focused on notebooks, sources, and chat with OpenRouter.
